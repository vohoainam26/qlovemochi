# Demos and standalone exports

- `standalone/` — self-contained HTML files that can be opened or shared without the main website assets.
- `mix-to-boba/` — the four-series Mix-to-Boba document used by the embedded website chapter, plus its reference version.
- `traditional-mochi/` — Traditional Mochi ring reference demo.
- `four-series/` — archived four-series showcase document.
- `references/` — preserved reference material.

The running website loads the Mix-to-Boba chapter from `mix-to-boba/qlove-mix-to-boba-demo2.html`.
